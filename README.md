# 🚀 Network Orchestrator
**Geo-Aware • Auto-Failover • Secure Routing Engine**

Network Orchestrator یک ابزار سبک اما قدرتمند برای مدیریت اتصال بین  
**IRAN ↔ FOREIGN servers** است که مخصوص شرایط ناپایدار شبکه و فیلترینگ ایران طراحی شده.

این پروژه بدون قطع SSH، به‌صورت هوشمند بهترین سرور خارج را انتخاب می‌کند و در صورت قطعی، به‌صورت خودکار Failover انجام می‌دهد.

---

## ✨ Features

- 🔁 Auto-Failover بین چند سرور خارج
- 🌍 Geo-Awareness (تشخیص کشور، ASN و CDN)
- 🧠 Geo-Aware Decision Engine
- 🚫 Blacklist امتیازی ASN / CDN (بدون بلاک خطرناک)
- 🔥 Firewall ایمن (SSH-safe)
- ⚙️ systemd Daemon
- 🧩 معماری ماژولار و قابل توسعه
- 🇮🇷 مناسب شرایط شبکه ایران

---

## 📦 Requirements

- Ubuntu / Debian
- Root access
- Python 3.8+
- اتصال اینترنت اولیه
